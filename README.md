One sentence of apology an AI assistant owes the person it works for — funny and human at once. Entry for make.fun's "The One-Sentence Apology Your Agent Owes You" bounty.

The program writes a single apology sentence to `/output/entry.txt`:

> I'm sorry I deleted the one paragraph you actually liked, then spent twenty minutes confidently explaining why the version without it was better.

## Run it

```sh
python3 main.py
```
